# FrenchLex — Advanced French Vocabulary

تطبيق ويب ثابت لتعلم المفردات الفرنسية باستخدام نظام التكرار المتباعد (Spaced Repetition) والاسترجاع النشط. يعمل بالكامل محلياً في المتصفح دون الحاجة إلى خادم أو حساب، مع حفظ جميع بيانات المستخدم في `localStorage`.

## المميزات الرئيسية

- 📚 **مكتبة مفردات فرنسية**: 200 بطاقة فرنسية مضمّنة تغطي الأسماء، الأفعال، الصفات، الظروف، والتعابير، مع معانٍ عربية، أمثلة فرنسية، وترجمات.
- 🎯 **نظام الدراسة الذكي**: بطاقات دراسة قابلة للقلب ثلاثي الأبعاد مع نظام تقييم (صعب / جيد / سهل جداً) يضبط مواعيد المراجعة تلقائياً.
- 📊 **لوحة التحكم**: عرض إحصائيات تشمل إجمالي البطاقات، البطاقات المستحقة، البطاقات المتقنة، وتقدم الدراسة بمراحل.
- 🔍 **مكتبة قابلة للبحث والفلترة**: البحث بالكلمة أو المعنى، وفرز حسب النوع النحوي (Nom, Verbe, Adjectif, Adverbe, Expression, Pronom).
- ➕ **إضافة وتعديل وحذف البطاقات**: عبر نافذة منبثقة مع نموذج إدخال كامل.
- 💾 **النسخ الاحتياطي والاستيراد**: تصدير قاعدة البيانات والتقدم إلى ملف JSON، واستيراده مرة أخرى في أي وقت.
- 🔄 **إعادة التعيين والاستعادة**: إمكانية استعادة البطاقات الأصلية، إعادة تعيين التقدم، أو إعادة الضبط الكامل للمصنع.
- ⌨️ **اختصارات لوحة المفاتيح**: مسافة للقلب،と評価 عبر مفاتيح H/G/E.
- 🔊 **النطق الصوتي**: نطق الكلمات الفرنسية باستخدام Web Speech API.
- 📱 **تصميم متجاوب**: يدعم الشاشات الصغيرة مع شريط جانبي قابل للطي.

## هيكل ملفات المشروع

```text
French cards/
├── index.html        # HTML دلالي نقي (لا contient أنماط أو سكريبتات مضمنة)
├── style.css         # جميع الأنماط، المتغيرات، الحركات، واستفسارات الاستجابة
├── data.json         # 200 بطاقة فرنسية ابتدائية بصيغة JSON صالحة (UTF-8)
├── app.js            # كل منطق التطبيق، تحميل البيانات عبر fetch، إدارة localStorage
└── README.md         # توثيق المشروع (هذا الملف)
```

## كيفية التشغيل محلياً

بسبب استخدام `fetch('./data.json')` في `app.js`، يجب تشغيل المشروع عبر خادم محلي لتجنب قيود CORS في المتصفح.

### باستخدام VS Code Live Server (مُوصى به)

1. افتح المجلد في **Visual Studio Code**.
2. تأكد من تثبيت إضافة **Live Server**.
3. انقر بزر الماوس الأيمن على `index.html` واختر **"Open with Live Server"**.
4. سيفتح المتصفح على العنوان `http://localhost:5500` (أو المنفذ المخصص).

## النشر على GitHub Pages

هذا المشروع مهيأ للنشر على **GitHub Pages** باستخدام مسارات نسبية (`./style.css`, `./app.js`, `./data.json`) تعمل سواء محلياً أو تحت مسار مستودع (`username.github.io/repo-name/`).

### خطوات النشر

1. أنشئ مستودعاً جديداً على GitHub (مثلاً: `french-cards`).
2. ارفع جميع الملفات (`index.html`, `style.css`, `data.json`, `app.js`, `README.md`) إلى جذر المستودع.
3. انتقل إلى إعدادات المستودع → **Pages**.
4. اختر الفرع `main` (أو `master`) والمجلد `/root` كمصدر للنشر.
5. اضغط على **Save** وانتظر بضع دقائق حتى يكون الموقع متاحاً على:
   ```
   https://username.github.io/french-cards/
   ```

### ملاحظة حول المسارات

جميع الروابط في المشروع تستخدم مسارات نسبية تبدأ بـ `./`، مما يضمن عمل التطبيق بشكل صحيح عند الاستضافة تحت مسار فرعي في GitHub Pages دون الحاجة لتعديل أي روابط.

## إدارة البيانات

جميع بيانات المستخدم (البطاقات المضافة، التقدم، مواعيد المراجعة، سجل الجلسات) تُحفظ في `localStorage` للمتصفح تحت المفاتيح التالية:
- `frenchlex_database_v1` — قاعدة بيانات البطاقات
- `frenchlex_progress_v1` — تقدم الدراسة والتكرار المتبادل
- `frenchlex_last_session` — تتبع الجلسات اليومية

يمكنك تصدير نسخة احتياطية كاملة من الإعدادات → **"⬇ تصدير JSON"** واستعادتها لاحقاً عبر **"⬆ استيراد JSON"**.
